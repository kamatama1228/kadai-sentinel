# Gemini(Antigravity)で使う手順

Gemini を使っている人向けの、いちばんやさしい手順です。Windows を想定しています。
所要時間は 30 分くらい。コマンドは **コピーして貼り付けて Enter** するだけです。

> 2026年6月に「Gemini CLI」は終了し、後継の **Antigravity**(アンチグラビティ)になりました。
> 古い記事に出てくる `gemini` コマンドは使えません。

## 用意するもの

- Windows の PC
- Google アカウント(ふだん Gemini で使っているもの)
- 大学の Moodle にログインできること
- Chrome か Edge

Git やプログラミングの知識はいりません。

---

## 1. Antigravity を入れる

1. ブラウザで <https://antigravity.google/> を開き、Windows 版をダウンロードしてインストールする
2. 起動して、Google アカウントでログインする

> 黒い画面(ターミナル)で使う版(`agy`)もあります。慣れている人はそちらでも同じように使えます。
> 入れ方:スタートボタンを右クリック →「ターミナル」を開いて
> `irm https://antigravity.google/cli/install.ps1 | iex` → 終わったら `agy install` → ターミナルを開き直して `agy`

## 2. uv を入れる(ツールを動かすための道具)

スタートボタンを右クリック →「ターミナル」を開き、次を貼り付けて Enter。

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

終わったら **ターミナルを一度閉じる**。Python は次の手順で自動で入るので、別に入れなくて大丈夫です。

## 3. このツールをダウンロードする

1. GitHub のこのページで、緑色の **Code** →「**Download ZIP**」を押す
2. ダウンロードした ZIP を右クリック →「すべて展開」
3. できたフォルダを、分かりやすい場所(例:ドキュメント)に置く

## 4. 準備のコマンドを実行する

1. 3 のフォルダを開き、何もないところで右クリック →「ターミナルで開く」
2. 次を 1 行ずつ貼り付けて Enter

```powershell
uv sync
Copy-Item .env.example .env
notepad .env
```

3. メモ帳が開くので、`MOODLE_URL=` の右を **大学の Moodle の URL**(最後の `/` なし)に書き換えて保存する

## 5. Moodle にログインする(ここだけは自分でやる)

同じターミナルで:

```powershell
uv run moodle login --sso
```

URL が表示されたら、次の順にやります。

1. Chrome か Edge で **F12** を押す → 上のタブから「**ネットワーク**(Network)」を選ぶ
2. 「**ログを保持**(Preserve log)」にチェックを入れる
3. 表示された URL をそのブラウザで開き、いつもの大学のログイン画面でログインする
4. 一覧から `launch.php` をクリック →「ヘッダー」の `location: moodlemobile://token=...` を `moodlemobile://` から最後まで **コピー**
5. ターミナルに戻って **Enter**(コピーした内容を自動で読み取ります)

```powershell
uv run moodle tasks
```

で課題の一覧が出れば完了です。

> コピーした `token=...` は **あなた専用の鍵** です。Gemini のチャットにも、友達にも貼らないでください。

## 6. Antigravity に頼んでみる

Antigravity で「フォルダを開く」から 3 のフォルダを開き、チャットで頼みます。

- 「今週の締切を教えて」
- 「〇〇の第 3 回の資料を要約して」
- 「未提出の課題ある?」

AI がコマンドを実行しようとすると **「実行してよいか」の確認** が出ます。`uv run moodle ...` なら許可して大丈夫です。
**確認を出さない設定(Turbo など)にはしないでください。**

## 7. Discord 通知

小テストの公開や締切の通知は、**共有の Discord チャンネルに入るだけ** で届きます。設定はいりません。
自分専用の通知(未提出リマインド)も欲しい人は、README の「Discord 通知」を見てください(少し難しいです)。

## 困ったとき

| こうなった | こうする |
| --- | --- |
| `uv` が見つからないと言われる | ターミナルを閉じて開き直す。だめなら PC を再起動 |
| `invalidtoken` と出る | ログインが切れた。5 をもう一度やる |
| `launch.php` が見つからない | 「ログを保持」にチェックを入れ直して、URL をもう一度開く |
| AI が `.env` の中身を見ようとする | 断ってよい。中身は人にも AI にも見せない |

## 知っておくこと

- スマホの Gemini アプリからは、このツールは動かせません(PC の中でコマンドを動かす仕組みがないため)
- Antigravity は無料でも使えますが、週ごとの使用量に上限があります
- 学生向けの Google AI Pro 無料特典(2025年に申し込んだもの)は、12か月たつと自動で有料(月 2,900 円)に切り替わります。続けないなら Google のアカウント設定で解約しておきましょう(2026年10月時点の情報)
- 授業の資料は、履修していない人に渡さないでください
