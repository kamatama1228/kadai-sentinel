# ログインのしかた

このツールは、公式の Moodle モバイルアプリと同じ方法で「トークン」を受け取り、それを使って Moodle の Web サービス API を読みます。パスワードは保存せず、トークンだけを `.env` に保存します。

まず `uv run moodle diagnose` で、大学の Moodle のログイン方式を調べてください。

## ユーザー名とパスワードでログインする大学

```bash
uv run moodle login
```

Moodle 標準の `login/token.php`(サービス `moodle_mobile_app`)でトークンを受け取ります。

## SSO(学認・Microsoft アカウントなど)でログインする大学

```bash
uv run moodle login --sso
```

公式アプリの「ブラウザでログイン」と同じ流れです。

1. `login --sso` が表示した URL をブラウザで開き、いつもの画面でログインする
2. ログインが終わると、ブラウザは `moodlemobile://token=...` という、公式アプリを開くためのリンクに移ろうとします。アプリが入っていない PC では何も起きず、白い画面のままになります
3. そのリンクを取り出してターミナルに貼り付ける

リンクはブラウザの開発者ツール(F12)で見ることができます。

1. ログインする前に F12 →「ネットワーク」タブを開き、「ログを保持」にチェック
2. 一覧の `launch.php` を選び、レスポンスヘッダーの `location: moodlemobile://token=...` をコピー
3. ターミナルに戻って Enter(Windows はクリップボードから自動で読み取ります)

Moodle の「プロフィール → セキュリティキー」画面にトークンが表示される大学では、それを `uv run moodle login --manual` で貼り付けることもできます。

受け取ったリンクは、サイトの URL とログインごとに作る合言葉(passport)から計算した署名で、本物かどうかを確かめています。

## 注意

- トークンはパスワードと同じです。人に渡したり、Git にコミットしたりしないでください
- 大学の Moodle でモバイルアプリ用の Web サービスが無効になっている場合、このツールは使えません。その場合は使わないでください
- トークンが切れたら(`invalidtoken`)、もう一度ログインしてください
